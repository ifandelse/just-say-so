## Three pillars

<CardGrid>
  <Card title="Vale lints the prose" icon="approve-check">
    [Vale](https://vale.sh) is a prose linter. The plugin runs it on the files the agent writes, on the text it publishes through `gh` and MCP tools, and on each chat reply, under rules you control in `.vale.ini`.
  </Card>
  <Card title="Judgment rules cover the rest" icon="document">
    "Lead with the answer" is an instruction the model follows, not a pattern a linter can match. The plugin injects those rules at every context start, into every subagent, and again after a reply broke one.
  </Card>
  <Card title="Your rejections become advice" icon="setting">
    When a reply is bad in a way you noticed, `/just-say-so:restate` has the model rewrite it and records the miss with a tag. The records build into a summary, and the summary into advice on your own setup.
  </Card>
</CardGrid>

## Install

```
/plugin marketplace add ifandelse/just-say-so
/plugin install just-say-so@just-say-so
```

Then run `/just-say-so:init` in a project. The [README](https://github.com/ifandelse/just-say-so#readme) has the full install and a first look at what the agent sees. The guides and the tutorial are on their way here; the [reference](/reference/the-rules/) is already complete.
