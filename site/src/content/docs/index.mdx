## Three pillars

<CardGrid>
  <Card title="Vale lints the prose" icon="approve-check">
    [Vale](https://vale.sh) is a prose linter. just-say-so runs Vale on the
    files the agent writes, on the text it publishes through MCP & CLI tools,
    and on each chat reply, under rules you control in `.vale.ini`.
  </Card>
  <Card title="Judgment rules cover the rest" icon="document">
    "Lead with the answer" is an instruction the model follows, not a pattern a
    linter like Vale can match. just-say-so injects those judgment rules at
    every context start, into every subagent, and again after a reply broke a
    rule.
  </Card>
  <Card title="Your rejections become advice" icon="setting">
    When an agent chat reply is bad, `/just-say-so:restate` has the model
    rewrite it and record the miss with a tag. Over time, these records build
    your case on how you want the agent to talk to you. Those records can be
    used to provide configuration advice to improve how you use the plugin.
  </Card>
</CardGrid>

## Install

```
/plugin marketplace add ifandelse/just-say-so
/plugin install just-say-so@just-say-so
```

Then run `/just-say-so:init` in a project. The [README](https://github.com/ifandelse/just-say-so#readme) has the full install and a first look at what the agent sees. The guides and the tutorial are on their way here; the [reference](/reference/the-rules/) is already complete.
