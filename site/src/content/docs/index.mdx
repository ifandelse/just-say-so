## What the plugin does

<CardGrid>
  <Card title="Linting of generated text" icon="approve-check">
    [Vale](https://vale.sh) is a prose linter. just-say-so runs Vale on the
    files the agent writes, on the text it publishes through MCP & CLI tools,
    and on each chat reply, under rules you control in `.vale.ini`.
  </Card>
  <Card title="Proactive communication rules" icon="document">
    "Lead with the answer" is an instruction the model follows. No linter
    pattern can match it. just-say-so injects those judgment rules at every
    context start, into every subagent, and again after a reply broke a rule.
  </Card>
  <Card title="Guided self-improvement" icon="pencil">
    When an agent chat reply is bad, `/just-say-so:restate` has the model
    rewrite it and record the miss with a tag. Over time, these records build
    your case on how you want the agent to talk to you. Those records can be
    used to provide configuration advice to improve how you use the plugin.
  </Card>
</CardGrid>

## Install

```
/plugin marketplace add ifandelse/just-say-so
/plugin install just-say-so@just-say-so
```

Then run `/just-say-so:init` in a project. [Getting started](/start/getting-started/) walks through one session in about fifteen minutes. [From the ground up](/tutorial/) continues that path through blocking, publishing, packages, and your own bullets. The [how-to guides](/guides/) take one task each, the [commands](/commands/) and [configuration](/configuration/) pages are the reference, and [concepts](/concepts/) explain why the pieces work the way they do.
